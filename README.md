# Tutti Frutti Online Privado 🍓🔒

Juego Tutti Frutti (Stop / ¡Basta!) online multijugador con salas privadas protegidas por PIN y control de moderación (expulsión) por el anfitrión.

## Novedades de Seguridad
- **PIN de acceso:** El anfitrión puede definir un PIN opcional para evitar que personas extrañas se unan.
- **Botón de Expulsión (Kick):** El creador de la sala puede expulsar a cualquier intruso de la lista de jugadores en tiempo real.
- **Selector de temas:** Modos Claro, Sepia Papel, Noche y Neón.
